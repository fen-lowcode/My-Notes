here are some great **step-by-step resources to learn GLSL (OpenGL Shading Language) from zero** — beginner-friendly and practical:

---

## 📘 **Free Interactive Tutorials & References**

### 🟡 **The Book of Shaders**

👉 [https://thebookofshaders.com](https://thebookofshaders.com)

- Very beginner-friendly
    
- Explains shader basics visually
    
- You write GLSL right in the browser
    
- Focuses on fragment shaders (great first step)
    

---

### 🟢 **LearnOpenGL — GLSL Essentials**

👉 [https://learnopengl.com/Getting-started/Shaders](https://learnopengl.com/Getting-started/Shaders)

- Practical intro with examples
    
- Shows how vertex & fragment shaders work
    
- Written specifically for modern OpenGL
    
- Excellent explanations of uniforms, attributes, and transformations
    

---

### 🔵 **OpenGL Shading Language (The Orange Book) Online Reference**

👉 [https://www.khronos.org/opengl/wiki/Shader](https://www.khronos.org/opengl/wiki/Shader)

- Official GLSL spec overview
    
- Good for deeper understanding after basics
    

---

### 🟣 **glslsandbox / ShaderToy**

👉 [https://www.shadertoy.com](https://www.shadertoy.com)  
👉 [https://glslsandbox.com](https://glslsandbox.com)

- These are **creative coding playgrounds**
    
- Tons of examples you can remix
    
- Great for learning effects by experimentation
    

---

## 🧪 Practice and Deepen Knowledge

### 💡 **Shader Frog / Shadero**

Online shader editors with visual previews

- [https://shaderfrog.com](https://shaderfrog.com)
    
- [https://shadero.com](https://shadero.com)
    

Great for building intuition by tweaking parameters and seeing live results.

---

## 📌 Suggested Learning Path

1. **Start with visuals**
    
    - The Book of Shaders
        
    - ShaderToy experiments
        
    - Understand color, coordinates, fragment output
        
2. **Learn basics of vertex vs fragment shaders**
    
    - LearnOpenGL tutorials
        
    - How geometry flows through the pipeline
        
3. **Explore uniforms and attributes**
    
    - Make simple procedural animations
        
    - Modify geometry normals, time feeds, etc.
        
4. **Apply to raylib / your projects**
    
    - Shader examples in raylib
        
    - Bake lighting, texture sampling, heightmap visuals
        

---

## Tips to Learn Faster

✅ Write _small shaders_ — one idea at a time  
✅ Use tools like ShaderToy to test ideas instantly  
✅ Compare shader code between examples  
✅ Read the spec only after you’ve played with code
